🚐 Nganya Smart Assist

Live WhatsApp-Based Matatu Tracking Platform

Currently deployed and used by passengers in Rongai.

About the Project

Nganya Smart Assist is a WhatsApp-based transport assistant that allows passengers to receive real-time vehicle locations, driver status updates, route alerts, and transport information directly through WhatsApp.

Features

  • 📍 Real-Time Vehicle Tracking
  • 🔔 Passenger Alerts
  • 📱 WhatsApp Integration
  • ☁ Firebase Backend
  • 🛰 GPS Tracking
  • 🚐 Multi-Nganya Support

Technologies Used

  • Python
  • Flask
  • Firebase Realtime Database
  • Twilio API
  • SQLite
  • OwnTracks GPS
  • Sinotrack ST906L
  • GitHub

Architecture

Driver
   ↓
GPS Tracker
   ↓
Flask Backend
   ↓
Firebase
   ↓
Twilio WhatsApp
   ↓
Passenger
